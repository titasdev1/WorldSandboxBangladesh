# World Sandbox: Bangladesh

Godot 4.x 3D Bangladesh-inspired open-world sandbox foundation.

Current vertical slice:
- Procedural 3D city and roads
- Buildings and landmark
- Day/night lighting
- Rain toggle
- Third-person movement
- Cars, CNG-style vehicles and rickshaw-style traffic
- Pedestrians
- Local currency economy
- Fare bargaining
- Wanted system
- Delivery mission and reward
- Android CI pipeline

Controls: WASD to move, E to bargain/interact, mouse click to increase wanted level, R to toggle rain.

The architecture is modular for larger missions, shops, combat, richer vehicles, multiplayer systems and licensed map providers.
